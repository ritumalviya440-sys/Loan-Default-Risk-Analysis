# Loan Default Risk Analysis

## Project Overview

An end-to-end BFSI Data Analytics project using SQL and Power BI to analyze loan default patterns, identify high-risk borrower segments, and support better lending decisions through data-driven insights.

The project focuses on understanding borrower characteristics, loan attributes, and financial factors associated with loan defaults.

## Tools Used
- MySQL
- Power BI
- GitHub

## Business Problem

A lending company faces the risk of financial losses when borrowers fail to repay their loans. The company needs to understand which borrowers and loan categories are more likely to default so that it can improve its lending decisions and manage credit risk more effectively.

The company needs better insights into borrower risk patterns to identify high-risk segments, understand the factors associated with loan defaults, and determine which loan applications may require additional scrutiny from the credit team.

### Business Problem Statement

How can a lending company identify high-risk borrowers, understand the factors associated with loan defaults, and improve its lending decisions to minimize potential financial losses?

## Business Objectives

- Identify borrower segments with higher loan default rates.
- Analyze the relationship between borrower financial characteristics and loan defaults.
- Understand how loan attributes such as loan amount, interest rate, loan term, and loan grade relate to default behavior.
- Identify potentially risky loan applications that may require manual review by the credit team.
- Develop a risk analysis dashboard to support data-driven lending decisions.
- Provide actionable business recommendations to help reduce lending risk.

## Dataset

**Dataset Name:** Loan Data  
**File Name:** `loan data.csv`  
**Database Table:** `loans`  
**Data Format:** CSV

This project uses historical loan data to analyze borrower characteristics, loan attributes, and repayment behavior.

The dataset will be used to explore loan default patterns, identify customer segments associated with higher default rates, and understand the relationship between borrower financial characteristics and loan repayment outcomes.

Data exploration, data quality checks, and SQL-based analysis will be performed to prepare the dataset for further analysis and visualization in Power BI.
